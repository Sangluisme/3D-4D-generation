# 3D/4D Generation Methods Summary

A survey of recent advanced 3D and 4D generation papers, each summarized in one sentence and categorized along two axes: **generation target** (object vs. scene) and **method family** (diffusion / auto-regression / flow-matching / score-distillation optimization / feed-forward regression / GAN). The method taxonomy is shared identically between 3D and 4D so the two domains are directly comparable.

- [3D Generation](3D-generation/README.md) → **[papers.md](3D-generation/papers.md)**
- [4D Generation](4D-generation/README.md) → **[papers.md](4D-generation/papers.md)**

Also covers papers on **editing** existing generated content, categorized by a self-chosen method taxonomy per domain:
